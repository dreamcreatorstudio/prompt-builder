Prompt Builder

Pick a combination, copy the prompt and try variants by changing one block at a time.

About this project — An experimental tool for learning and creating image prompts. Explore combinations, change one block at a time, and discover what works for you. Results vary by generator, model and settings; prompts are a starting point, not a guarantee.

To compare: keep the same model, format and settings, and use the same seed when available. Lock keeps a block's choice in this tool; it doesn't make the generator keep the same face or body. Recipes are starting points — we call one tested only when it has recorded results with the platform and model used.
