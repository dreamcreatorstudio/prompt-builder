# Mezclador de Prompts

Herramienta web para armar prompts de imagen por **bloques**: foto, piel, modelo, cabello, ojos, cuerpo, vestuario, accesorios, cámara, luz y fondo. Eliges una opción numerada en cada bloque y copias el prompt listo.

**Úsalo aquí:** https://dreamcreatorstudio.github.io/prompt-builder/

## Qué hace
- Menús numerados por bloque (cabello 1 rubia, 2 pelirroja…).
- Formato y settings recomendados para **Venice AI**, **SeaArt** y **Perchance AI**.
- **Bloquear** un bloque y sacar **×3 variantes** cambiando solo ese bloque.
- **Recetas** cortas para compartir: `FOTO1 BRI2 MOD1 CAB5 OJO2 PIEL1 CUE1 VES1 ACC0 CAM1 LUZ1 FON1`.
- Funciona en PC y celular, sin instalar nada.

## Biblioteca
Todas las opciones están en [biblioteca.md](biblioteca.md).

## Normas de contenido
Personas adultas y ficticias, sin desnudos ni contenido sexual, sin personajes ni marcas registradas.

## Aportes
¿Tienes un bloque que da buenos resultados? Abre un *issue* con el texto, la plataforma y el seed.
